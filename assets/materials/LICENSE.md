Retrieved 2026-09-17. The 1K JPG packages were downloaded from ambientCG's official download endpoints. This project retains the original Color, NormalGL, Roughness and (where supplied) Metalness maps; files were renamed by channel but their image bytes were not modified. No downloaded executable scripts or external project files are included.

`sources.json` records each local file's original asset URL, download URL, license and SHA-256 checksum. Godot import settings enable mipmaps and mark normal textures as normal maps. The runtime uses shared PBR materials with mesh-local triplanar mapping over unscaled, metre-sized geometry, so resizing does not stretch textures and city movement does not slide geometry through the texture.
